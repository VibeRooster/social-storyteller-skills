# CTA library

| Stage | CTA | Example |
|---|---|---|
| TOF | Follow / Share | "Send this to a teammate who needs it." / brand tagline on end card |
| MOF | Save / link in bio | "Save this for later. The link's in the bio." |
| BOF | Specific next step | The concrete offer or action |

Rules:
- Never paste a URL into the video itself; use "link in bio".
- Keep a series' close consistent across episodes.
- If the recorded CTA deviates from the script, report it rather than silently fixing it.
