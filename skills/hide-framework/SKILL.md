# H.I.D.E. short-form framework

A fill-in-the-blank template for short videos built to get views. Pick one line from each of the four sections, fill in the blanks with your ideal client in mind, then shoot one sentence per shot.

| Beat | Job |
|---|---|
| **H**ook | Grab attention. It can be visual, audio, text, or all three. |
| **I**ntrigue | A one- or two-sentence story that holds back the value and increases watch time. |
| **D**eliver value | The point of the video: the information, advice or wisdom you want to share. |
| **E**xit with action | Get the viewer to do something (like, follow, buy, DM) so they engage and remember the value. |

## Steps
1. Name the ideal client and the task they are trying to do.
2. Pick one line per beat from [references/line-bank.md](references/line-bank.md) and fill in the blanks.
3. Map the sentences to shots (wide, then mid long, then mid close-up) using [references/shooting-your-script.md](references/shooting-your-script.md).
4. Check the result against the sample in [references/example-script.md](references/example-script.md).

## When to use something else
H.I.D.E. is for story-led clips. For timed explainers and demos, use [heit-script](../heit-script).
