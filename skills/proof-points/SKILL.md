# Proof points

- Never fabricate or round up a stat. Every stat traces to a library entry with a URL (`references/stat-library-template.md`).
- **Tiers**: Tier 1 (large samples, measured outcomes) is safe. Tier 2 needs a caveat. "Handle with care" means verify on the page before citing.
- Say what was measured (companies vs projects, pilots vs production).
- Label predictions as predictions ("X predicts…").
- Phrase vendor good-news stats as "companies report…" and name the sponsor.
- Don't misattribute popular figures; use the source's actual finding.
- Small-sample headline stats: state the sample or skip it.
- Evidence graphics show only figures from the source.
