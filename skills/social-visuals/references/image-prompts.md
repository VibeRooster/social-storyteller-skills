# Image-generation prompts
- Generate the illustration only; add text and brand in code.
- Name the style: "flat cartoon vector illustration, bold clean outlines, limited palette of [brand colors], plain background, no text".
- Spell out emotion and pose; name props unambiguously.
- Ask for "full body, feet visible, generous margin".
- For sequences, describe left-to-right order and each figure's single action.
- Generate 2 options, then pick or regenerate. Cut out subjects (e.g. rembg) when compositing.
- For well-known characters, describe a homage, not the trademark.
