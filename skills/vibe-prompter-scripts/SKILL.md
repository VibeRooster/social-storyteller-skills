# VibePrompter filming scripts

Write one `.md` file per series that opens cleanly in VibePrompter. Prefer this deliverable over a freeform shoot plan whenever the ask is a multi-piece Reel series (weekly picks, Basics ladder, tool deep-dives, and similar).

## Goal

One markdown file = one series:

1. Title header
2. Index table
3. Overview (~50s) — WHY
4. Five detail sections (`1/5`–`5/5`, each ~35–50s)
5. Open questions

Tables use the columns VibePrompter and the teleprompter workflow expect. See [references/structure.md](references/structure.md), [references/heit-table.md](references/heit-table.md), and [references/example-basics-ladder.md](references/example-basics-ladder.md).

## Steps

1. Confirm series topic, the piece list (five plus optional Overview), and whether demos are `SCR` (hub / screen) or `BRD` (board / Graphics).
2. Draft the index table from the brief, picks list, or ladder.
3. Write Overview HEIT focused on WHY; add one or two alt hooks.
4. Write each `1/5`–`5/5` with spoken + on-screen hooks, then HEIT rows timed in `s`.
5. Apply the current CTA and end-card note in the header and Teach rows.
6. List Open questions; save as `Series-name-scripts-vN.md` (never overwrite; bump `vN`); share the file path or OneDrive link.
7. Do not start a video build from this file alone — builds still need a plan and listed assets.

## Writing rules

- Overview = WHY. Detail scripts = how to use, read, or react (or one ladder rung each).
- Front-load the hook: spoken and on-screen hooks in the first seconds. For tool or pick Reels, put the verdict or money shot early when asked.
- Illustrate with concrete UI or board moves, not abstract claims.
- Teach ends with a team question or action when it fits, then the CTA.
- **CTA (Basics and later):** `If this helped, like and follow — it tells me to keep making these, and it helps other teams find them.` Add `Link is in my bio` only when there is a gallery. End card tiles: Like · Save · Follow over the last ~3.5s. Do not invent DM or manual-follow-up CTAs.
- Mark uncertain lines `[TIM: …]` instead of inventing personal facts.
- Keep spoken length filmable (~35–55s per piece). If a draft runs long, flag trim options in Open questions rather than silently cutting substance.
