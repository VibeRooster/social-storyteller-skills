| Column | Meaning |
|---|---|
| Beat | HEIT letters: Hook, Explain, Illustrate, Teach. Leave Beat blank on continuation rows under the same letter when one beat needs two or more VO lines. |
| VO | Spoken words, first person when on camera. Plain sentences; no stage directions inside VO. |
| s | Seconds for that row. Sum of a section ≈ target duration. Keep individual CAM lines short enough to film (~3–8s typical). |
| Type | `CAM` face-to-camera; `SCR` screen demo / hub; `BRD` whiteboard or Graphics overlay. Use `CAM / BRD` only when both are intentional in one beat. |
| Screen / visual | What the viewer sees — hub row to tap, graphic card name, “End card”, “—”, caption pull quotes, match-on-action notes (“Tim front → side on head turn”). |
